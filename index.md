# analogs

The analogs R package provides flexible, computationally efficient tools
for analog-based climate change analyses. Its core function is to search
an “analog pool” for data that best match each query site. Matching can
be based on a combination climatic similarity and geographic distance,
and matches can be processed in a variety of ways. This supports a range
of analyses including analog-based climate change velocity, analog
impact modeling, analog availability, and analog intensity.

## Installation

You can install the development version of analogs from
[GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("matthewkling/analogs")
```
